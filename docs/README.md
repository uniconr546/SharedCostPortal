# Tài liệu và Tài nguyên Minh họa Dự án (SharedCost Portal)

Thư mục này lưu trữ toàn bộ sơ đồ thiết kế, ảnh chụp giao diện và tài liệu đặc tả của dự án:
- `docs/diagrams/`: Chứa các sơ đồ Use Case, Class Diagram, State Machine, Sequence Diagram, Activity Diagram, BCE, ERD và Sơ đồ điều hướng màn hình.
- `docs/screenshots/`: Chứa ảnh chụp màn hình thực tế của các giao diện chức năng (FrmDangNhap, FrmBaoCaoThongKe, FrmCostPool, FrmDriver, FrmTarget, FrmAllocationRule, FrmRuleVersion, FrmSimulation, FrmAllocationRun, FrmReview, FrmLock, FrmTraceability, FrmAuditLog).
- `docs/report/`: Chứa báo cáo thuyết minh phân tích và thiết kế hệ thống (.docx).
